# Society Sandbox · 社会沙盒

探索新技术进入社会后，人的适应、法律规则和治理机制如何相互影响的公开研究项目。

**当前状态：立项与研究设计阶段，尚无可运行的模拟器。** 项目会在业余时间逐步推进，通过视频记录过程，欢迎观众参与讨论、提供资料和复现实验。

## 为什么做这个项目

在 AI 数字仿冒、隐私保护、内容溯源等具体领域，已经有官方报告指出法律保护缺口或监管配套不足。我们希望从这些现实信号出发，在沙盒里研究：技术扩散与制度响应之间的落差，何时会扩大风险，何时能够被现有制度或新措施缓解？

我们不需要等到严重后果全面出现，才开始研究早期信号。与此同时，模拟也需要允许制度及时响应、技术帮助人适应等不同结果。

## 核心问题

- 一项技术改变了哪些行为的成本、收益和传播速度？
- 既有规则能覆盖哪些行为，哪些责任仍不明确？
- 从发现问题，到制定规则、形成执行能力和提供救济，各需要多久？
- 不同响应时机和治理措施，如何影响损害、收益分配与创新空间？
- 哪些结论对参数与行为假设敏感，哪些在多种条件下仍然成立？

## 第一项候选实验

**AI 合成内容的扩散、标识与救济。** 这是待讨论的起点，可根据资料和可验证性调整。

模拟内容生产者、普通用户、平台和监管机构。比较基线、内容标识、投诉移除、不同执行能力和响应延迟等情景，观察误认、传播范围、损害暴露时长、误删与治理成本。

## 初步实现方向

采用基于主体的模拟（agent-based modeling）：由程序维护时间、资源、信息可见性、规则和行为后果，按需要引入大模型处理部分理解与互动。先建立可重复运行的小实验，再逐步扩展角色和场景。

技术栈、模型服务和界面形式尚未确定。首个基线实验应尽量能在本地运行，并保存参数、随机种子和事件日志。

## 如何看待结果

模拟结果是特定假设下的情景推演。我们会分别标明现实证据、模型假设和模拟发现；角色对话是否像人，不等于模型能预测现实。对照实验、参数敏感性和外部验证是研究的一部分。

## 参与这个研究

欢迎通过 Issues：

- 提交有来源的案例、法规、研究和数据；
- 指出已有规则其实能够处理某个问题，或提供相反证据；
- 提出可测量、可对照的实验问题；
- 复现实验、报告问题，或贡献代码和可视化。

请避免在公开讨论中提交当事人的隐私信息。第一阶段的具体任务见 [路线图](ROADMAP.md)，参与方式见 [贡献指南](CONTRIBUTING.md)。
