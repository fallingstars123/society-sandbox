# 研究与实验约定

## 候选问题

在 AI 合成内容传播场景中，规则响应延迟、平台执行能力和用户识别能力，如何共同影响损害暴露、误删与治理成本？首轮实验前再确定司法辖区、具体内容类型和校准数据。

## 最小环境

每一步可暂定为一天。程序维护内容、传播关系、各方可见信息、投诉与处理队列。主体只能根据可见信息采取动作；资源、处理能力和执行延迟由环境计算。

用户的信任与识别能力、生产者的动机、平台的处理能力和监管机构的信息都应允许差异。主体可以选择不行动。

## 对照设计

先建立简单规则基线，再按需加入大模型。分别改变规则响应延迟、标识机制、投诉移除和执行能力，采用相同初始条件及配对随机种子比较。记录重复运行次数和结果分布。

## 候选指标

- 有害内容的触达人数、传播规模与暴露时长。
- 误认率、误报率、误删率和申诉恢复时间。
- 投诉处理时间、积压量、重复上传与执行成本。
- 正常内容生产和传播所获得的收益及承担的成本。

指标的具体定义与单位须在运行实验前写清，不把“是否发布新法”单独作为治理成效。

## 可信度

明确区分法律文本、现实数据、经验判断与模型假设。大模型不得直接决定整体社会结果。检查行动顺序、提示词和随机性是否主导结果；保留配置、事件日志、模型版本和代码版本。使用独立数据验证可测部分，报告模型不能解释的部分。

## 每次实验的记录格式

问题 → 来源 → 假设 → 配置与版本 → 对照条件 → 指标 → 结果分布 → 敏感性 → 反例与局限 → 下一步。
